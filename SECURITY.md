# Reporting a security issue

Contact the maintainer through the private channel listed on their GitHub profile. Include the affected version and a short reproduction using disposable files. Keep credentials and personal data out of public issues.

Activity Lab needs no WakaTime API key, GitHub token or other account credentials. Its optional online lookup reads the public WakaTime language catalog. Install VSIX packages from a source you trust.
