# Security Policy

Activity Lab tidak memerlukan WakaTime API key, token GitHub, atau kredensial akun lain.

Jika menemukan masalah keamanan, jangan mempublikasikan data sensitif atau bukti eksploitasi yang berdampak pada pengguna lain di issue publik. Hubungi maintainer melalui kanal pribadi yang mereka sediakan pada profil GitHub dan jelaskan langkah reproduksi yang aman.

Penting: fitur pemrosesan bahasa online hanya mengambil katalog publik WakaTime bila dipilih pengguna. Jalankan extension hanya dari sumber yang kamu percayai.
