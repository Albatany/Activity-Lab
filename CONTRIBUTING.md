# Contributing to Activity Lab

For a bug report, include your operating system, VS Code version and the shortest sequence that reproduces the problem. Remove personal paths and account details from logs before sharing them.

Make changes on a separate branch. Run `npm run check` and `npm test`, then describe the behavior you tested in your pull request. Windows and Linux test results are welcome.

Keep generated files identifiable as simulations. Activity Lab uses local editor events and counters. Changes that collect credentials, impersonate users or submit fabricated tracker events fall outside the project.
