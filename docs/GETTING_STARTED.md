# Your first session

Install the current VSIX using **Extensions** and **Install from VSIX** in VS Code. Open the Command Palette with `Ctrl+Shift+P` on Windows or Linux, then run **Activity Lab: Start Session**.

For a short test, choose **Professional Modes**, select **Data Analyst** and leave the project name blank. Choose **5 minutes**, **Balanced (1:1)**, **30 seconds** and **Instant**. The confirmation shows the settings before Activity Lab opens the first file.

To build your own selection, choose **Choose multiple language**, check the profiles you want and press Enter. Choose **Save preset** and give it a name to make it available under **Saved Language** in later sessions.

Run **Activity Lab: Show Status** to find the scratch folder. Click the status bar item to stop. Open `session-report.json` in that folder to see the files and the number of completed edits. After a session ends, you can delete its directory to reclaim space.
