# IntelliJ IDEA 6.0.1 Release Notes

This release introduced foreground-aware local scheduling, editor event handling, and improved local session diagnostics. It is retained here as release history. The standalone 6.1.0 edition removes tracker-oriented diagnostics and keeps the local session engine.

Install the current build from `release/activity-lab-intellij-6.1.0.zip` through **Settings → Plugins → Install Plugin from Disk...**.
