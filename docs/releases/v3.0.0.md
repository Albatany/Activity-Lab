# Activity Lab 3.0.0

Three edit patterns controlled the number of generated additions and deletions. The options were balanced (1:1), steady growth (4:1) and fast growth (8:1). Session totals were saved to `session-report.json`. This release also added safeguards for scratch files.

Install `activity-lab-synthetic-3.0.0.vsix` with **Install from VSIX**. The counts describe local operations.
