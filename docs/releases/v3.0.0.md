# Activity Lab v3.0.0 — Local Line-Change Patterns

**By Albatany · © Albatany 2026**

Version 3 introduces controlled additions/deletions for local editor tests.

## What's new
- Three patterns for generated scratch lines: **balanced (~1:1)**,
  **additions favored (~4:1)**, and **strongly favored (~8:1)**.
- Local simulated additions/deletions counters.
- A session report saved as `session-report.json`.
- File and session safeguards around synthetic edits.
- Keeps the v2 language catalog and long-session options.

## Upgrade
Install `activity-lab-synthetic-3.0.0.vsix` using VS Code's
**Install from VSIX** command.

> Line counters in Activity Lab reflect only local generated operations; they
> are **not** additions/deletions confirmed by WakaTime or another provider.
