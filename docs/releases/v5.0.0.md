# Activity Lab v5.0.0 | Custom Language Selection

**Major release · October 24, 2026**

Activity Lab 5.0 introduces a flexible, international experience for users who want to design their own language combinations in Visual Studio Code editor simulations.

## What's new

* **Choose multiple languages.** Search and select your own combination from 141 bundled language and file profiles, including Python, TypeScript, SQL, Assembly, Bash, Rust, Go, and Markdown.
* **Save reusable presets.** Store up to 20 named language combinations locally, reopen them later, or delete unused presets through a new Command Palette action.
* **English everywhere.** All command titles, menus, prompts, notifications, status text, confirmation dialogs, and documentation now use English.
* **Expanded reports.** Each session records the selected language list and whether it used a custom multi-select, saved preset, curated mode, or single profile.
* **More regression tests.** The local test suite exercises custom selection, saved presets, multiple sandbox files, ratio calculations, and the existing session controls.

## Still included

32 professional technology modes, the offline 141-profile catalog, optional online WakaTime catalog, project name labels, randomized scratch files, three local additions/deletions patterns, durations up to eight hours, and **Until I Stop**.

## Upgrade

Install `activity-lab-synthetic-5.0.0.vsix` over an older version using **Extensions → Install from VSIX**. The extension identifier remains `localdev.activity-lab-synthetic`.

## Important limitations

Activity Lab creates **synthetic editor changes**, not human coding work. It does not directly send WakaTime heartbeats, and it cannot guarantee statistics in WakaTime or other tracking services. Local line counts are for experiments only. Automated tests use a simulated VS Code API and do not prove real-world tracker acceptance.

## Compatibility

VS Code 1.85+ · Windows and Linux, including Kali Linux · No credentials required
