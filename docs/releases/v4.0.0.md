# Activity Lab v4.0.0 — GitHub Edition

**Latest stable release · Developed by Albatany · © Albatany 2026**

Activity Lab 4.0 brings a more polished, beginner-friendly Visual Studio Code
experience while preserving the simulator features introduced in v1–v3.

## ✨ Highlights

- **32 technology modes**, including Full Stack, Backend, Data Analyst,
  Data Scientist, AI Engineer, MLOps, Cloud, DevOps, and Cyber Security.
- **141 built-in language/file profiles** with optional online language lookup.
- **Custom project name** stored in `.wakatime-project` in an isolated test folder.
- **Randomized scratch filenames** such as `api_routes_*.ts`,
  `debugging_*.cpp`, and `model_training_*.py`.
- **Three local additions/deletions patterns** (~1:1, ~4:1, ~8:1).
- Timed experiments up to **8 hours** and **Until I Stop** mode.
- Clearer Indonesian interface text, local session reports, and safe file limits.
- Refreshed README, guides, open-source license, and GitHub Actions tests.

## 🔄 Updating from v1, v2, or v3

1. Download **`activity-lab-synthetic-4.0.0.vsix`** from the release assets.
2. Open Visual Studio Code.
3. Select **Extensions → … → Install from VSIX**.
4. Choose the downloaded file and reload VS Code if requested.
5. Open the Command Palette and run **Activity Lab: Mulai Simulasi**.

The extension ID remains `localdev.activity-lab-synthetic`, so existing
installations can be upgraded without installing another independent extension.

## ⚠️ Important limitation

Activity Lab generates **synthetic file edits** in an isolated workspace.
Its local counts are not real coding achievements, and neither WakaTime nor
other editor activity trackers are guaranteed to accept or count those edits.
This software does not submit fabricated WakaTime API heartbeats.
