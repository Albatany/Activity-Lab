# Activity Lab 4.0.0

This release introduced 32 professional modes, optional project names and randomized scratch filenames. Reports included the selected mode and generated file names. The extension retained the 141 built-in profiles, three edit patterns and eight-hour or open-ended sessions. This version shipped an Indonesian interface.

Install `activity-lab-synthetic-4.0.0.vsix` with **Install from VSIX** in VS Code 1.85 or later. The extension ID stayed the same for upgrades.
