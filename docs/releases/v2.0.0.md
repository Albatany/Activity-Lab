# Activity Lab v2.0.0 — Languages & Long Sessions

**By Albatany · © Albatany 2026**

Version 2 expands Activity Lab into a broader editor-testing playground.

## What's new
- **141 language/file profiles** including Assembly, SQL, Bash, Markdown,
  Python, Rust, TypeScript, Dockerfile, and many others.
- Optional online WakaTime language catalog and custom file types.
- Full-stack language rotation.
- Longer scheduled sessions of up to **8 hours**.
- **Until I Stop** mode for manual session control.

## Upgrade
Install `activity-lab-synthetic-2.0.0.vsix` using VS Code's
**Install from VSIX** command. The extension identifier is unchanged.

> Synthetic edits do not guarantee any WakaTime heartbeat or dashboard time.
