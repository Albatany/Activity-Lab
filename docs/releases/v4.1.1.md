# Activity Lab 4.1.1

The language source menu now gives each choice its own icon. Professional Modes groups 44 roles by field, with a role icon, the languages used in each rotation and a short description. The Activity Lab flask and terminal cursor appear in the extension details and README.

Install `activity-lab-synthetic-4.1.1.vsix` with **Extensions: Install from VSIX**. Existing presets and the extension commands work as before.

Maintainers can publish the VSIX and its SHA256 checksum to GitHub Releases and GitHub Packages. The optional cleanup path retires a specific failed version after verifying the new downloads.
