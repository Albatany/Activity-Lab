# Activity Lab v1.0.0 — Initial Release

**By Albatany · © Albatany 2026**

The first version of Activity Lab provides an isolated Visual Studio Code
workspace for exploring automatically generated editor changes on Windows and
Linux.

## Highlights
- 12 programming-language choices.
- Start, Stop, and Status commands in VS Code.
- Session durations from 5 to 120 minutes, with configurable edit intervals.
- Clearly labeled scratch files and `.wakatime-project` identification.
- Initial installer and testing instructions.

## Install
Download `activity-lab-synthetic-1.0.0.vsix` from this GitHub Release and use
**VS Code → Extensions → … → Install from VSIX**.

> This is a synthetic editing test utility, not a tool for proving coding
> time or professional productivity. Third-party trackers may not count it.
