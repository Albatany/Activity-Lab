# Activity Lab 4.1.0

Select any of the 141 built-in profiles and use them once or save a named preset. Manual selections run in shuffled rounds. Open **Saved Language** to use or delete a preset.

Professional Modes now covers 44 fields. Each mode lists the exact profiles it uses. New fields include accessibility, audio software, compilers, design systems, developer tools, FPGA design, geospatial development, graphics, observability, release engineering, search and statistical programming.

Samples vary by language and include declarations, functions, loops and structured data. Choose **Character by character** to watch a batch as it is typed. **Instant** remains the default. The interface, messages and documentation are in English.

Install `activity-lab-synthetic-4.1.0.vsix` with **Install from VSIX**. Existing installations use the same extension and command IDs.
