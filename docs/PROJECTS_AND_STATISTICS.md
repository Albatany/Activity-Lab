# Project names and session statistics

The `.wakatime-project` file contains the name chosen during setup. WakaTime can use this marker for project detection when it records an event. Changing the marker does not rename existing dashboard history.

Activity Lab edits scratch documents through the VS Code editor API and saves completed steps. Other extensions may observe those events. Local addition and deletion counts come from the selected edit pattern. JSON counts entries and Whitespace counts instruction samples.

To compare a short test with an external tracker, check the tracker before and after the session. If you use WakaTime, check its extension, authentication and debug logs separately. Generated activity does not establish working hours or professional experience.
