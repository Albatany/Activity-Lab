# Activity Lab Standalone 6.1.2

**Current Stable Source Release**

Activity Lab Standalone 6.1.2 is the current stable source release by Albatany.

This release continues the standalone architecture while preserving native editor simulation workflows.

### Highlights

- Removed direct WakaTime integration and related configuration.
- Preserved native editor operations, including document editing, saving, and editor tabs.
- Refined generated simulation filenames.
- Retained 141 offline language and file profiles.
- Retained 32 professional modes and custom file profiles.
- Preserved saved languages, presets, session controls, and JSON reports.
- Improved IntelliJ session report consistency.

### Validation Status

- VS Code 6.1.2: automated tests and syntax checks passed.
- IntelliJ IDEA 6.1.2: source code included; installable plugin ZIP requires a successful Gradle build.
- Arduino Uno companion: included as a separately versioned 6.1.0 package; physical hardware upload has not been validated.

This release represents the current stable source baseline. Platform-specific build and hardware validation should be checked before distributing each installer.
